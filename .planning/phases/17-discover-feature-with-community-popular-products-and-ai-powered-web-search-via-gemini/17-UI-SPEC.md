## Spacing Scale

GiftMaison uses ad-hoc named tokens rather than a strict step-scale. All values are multiples of 2 (most are multiples of 4).

| Token | Value | Usage in Discover |
|-------|-------|-------------------|
| gap4 | 4 dp | Icon-to-label gap in nav slot; dot/separator spacing inside card metadata row |
| gap8 | 8 dp | Vertical spacing between card text lines (title → description → price) |
| gap10 | 10 dp | Vertical gap between successive `DiscoverProductCard` items in `LazyColumn` |
| gap12 | 12 dp | Vertical padding between section header and first card in that section |
| gap16 | 16 dp | Horizontal screen edge padding (left/right) for all content; vertical spacing between the search bar and first section header |
| gap20 | 20 dp | Top padding inside `Scaffold` body before the search `OutlinedTextField` |
| edge | 16 dp | `LazyColumn` horizontal content padding — matches screen edge on both sides |

Exceptions:
- `AsyncImage` 16:9 aspect ratio container: full-width (no horizontal padding), clips to card width. Top corners of the image follow the card's `radius16` shape.
- `OutlinedTextField`: full-width, `modifier = Modifier.fillMaxWidth().padding(horizontal = 16.dp)`. Height driven by Material3 default (`56 dp` tall per M3 spec).
- Section header row: `padding(horizontal = 16.dp, vertical = 12.dp)`.
- Card content padding (below image): `padding(horizontal = 12.dp, vertical = 10.dp)`.
- Shimmer skeleton card height: `56 dp` for text placeholder rows; full `AsyncImage` shimmer block at 16:9 ratio.

## Component Specifications

### Bottom Nav Slot 2 — Discover

- Icon: `Icons.Outlined.Search` (24 dp, stroked)
- Label: `R.string.nav_discover_tab` — "DISCOVER" (en) / "DESCOPERĂ" (ro)
- Typography: `monoCaps` (matches all other nav slot labels per Phase 9 CHROME-01)
- Selected state: `accentSoft` pill behind icon + `accent` stroke icon + `accent` label — identical behavior to other slots
- Source: CONTEXT.md D-01

### OutlinedTextField — Search Bar

- `modifier = Modifier.fillMaxWidth().padding(horizontal = 16.dp)`
- `leadingIcon = { Icon(Icons.Outlined.Search, tint = inkFaint) }`
- `placeholder = { Text(stringResource(R.string.discover_search_placeholder), style = bodyM, color = inkFaint) }`
- `singleLine = true`
- `keyboardOptions = KeyboardOptions(imeAction = ImeAction.Search)`
- `keyboardActions = KeyboardActions(onSearch = { viewModel.search(query); focusManager.clearFocus() })`
- Unfocused border: `line` (#DDD4C4)
- Focused border: `accent` (#C8623A) — Material3 OutlinedTextField default
- Shape: `radius12` (`RoundedCornerShape(12.dp)`)
- Top margin: `gap20` (20 dp) from Scaffold body top; bottom margin: `gap16` (16 dp) to first section header
- Source: CONTEXT.md D-35

### Section Headers

- Text: `GiftMaisonTheme.typography.monoCaps`
- Color: `inkFaint` (#9C8E7F) — tertiary treatment consistent with Phase 8/9 section label convention
- Padding: `padding(horizontal = 16.dp, vertical = 12.dp)`
- No divider line above first section; `HorizontalDivider(color = line, thickness = 1.dp)` between the web section and community section when both are visible
- Source: CONTEXT.md D-36

### DiscoverProductCard

Material3 `Card` composable.

- Card background: `paperDeep` (#EDE5D5)
- Shape: `radius16` (`RoundedCornerShape(16.dp)`) — matches registry cards (Phase 11)
- Elevation: 0 dp (flat card — consistent with Phase 10/11 flat card pattern; shadow provided by background contrast)
- Width: `fillMaxWidth()` with `padding(horizontal = 16.dp)` applied at the `LazyColumn` content level
- Vertical gap between cards: `gap10` (10 dp) as `verticalArrangement = Arrangement.spacedBy(10.dp)` in LazyColumn

**Image area:**
- `AsyncImage` composable (Coil 3)
- `modifier = Modifier.fillMaxWidth().aspectRatio(16f / 9f)`
- `contentScale = ContentScale.Crop`
- `placeholder = painterResource(R.drawable.discover_card_placeholder)`
- `error = painterResource(R.drawable.discover_card_placeholder)` (same drawable for both states)
- `contentDescription = null` (decorative; title below provides textual context)
- Top corners of image clip to `radius16`; bottom corners are square (card shape clips overall)

**Content area below image:**
- Padding: `padding(horizontal = 12.dp, vertical = 10.dp)`
- Vertical arrangement: `Arrangement.spacedBy(8.dp)`
- Title: `Text(title, style = bodyL, color = ink, maxLines = 2, overflow = TextOverflow.Ellipsis)`
- Description: `Text(description, style = bodyM, color = inkFaint, maxLines = 2, overflow = TextOverflow.Ellipsis)` — omit composable entirely if description is empty string
- Price: `Text(priceFormatted, style = bodyMEmphasis, color = ink)` where `priceFormatted = NumberFormat.getCurrencyInstance(Locale("ro", "RO")).format(price)` → "199,99 RON" format; omit if price == 0.0

**Tap behavior:**
- `Card(onClick = { … })` — opens `Intent(Intent.ACTION_VIEW, Uri.parse(retailerUrl))` wrapped in `try { startActivity(intent) } catch (e: ActivityNotFoundException) { snackbarHostState.showSnackbar(…) }`
- No ripple customization — Material3 default ripple on `paperDeep`
- Source: CONTEXT.md D-32, D-33, D-37

### discover_card_placeholder Drawable

A vector drawable (`res/drawable/discover_card_placeholder.xml`) with the following visual spec:

- Background: vertical gradient from `accentSoft` (#F3DED0, top) to `accent` (#C8623A, bottom) at 40% alpha — `android:startColor="@color/accentSoft"` / `android:endColor="@color/accent"` with `android:alpha="0.4"`
- Centered glyph: a simplified product-box / gift-box outline in `paper` (#F7F2E9) at 40% width of the bounding box. Use the Unicode glyph approach: a `<text>` element is not available in vector drawables; instead, a simple path-based box with a bow (3 rectangles: box body + lid + bow loop) drawn as `<path android:fillColor="@color/paper" android:alpha="0.7" …>`
- The visual language is consistent with `HeroImageOrPlaceholder`'s gradient-and-glyph pattern but uses a neutral gift-box icon rather than an occasion glyph
- Aspect ratio: designed at 16:9 (e.g., viewportWidth="160" viewportHeight="90")
- Source: CONTEXT.md D-37, Claude's discretion on exact look

### Loading State — Shimmer Skeletons

No third-party shimmer library. Implemented as custom shimmer using `Modifier.drawWithContent` with an animated `InfiniteTransition` brush sweep.

**Shimmer brush spec:**
```kotlin
val shimmerColors = listOf(
    colors.paperDeep,                            // base
    colors.line,                                 // highlight midpoint (#DDD4C4)
    colors.paperDeep,                            // base
)
val transition = rememberInfiniteTransition()
val translateAnim by transition.animateFloat(
    initialValue = 0f,
    targetValue = 1000f,
    animationSpec = infiniteRepeatable(
        animation = tween(durationMillis = 1200, easing = FastOutSlowInEasing),
        repeatMode = RepeatMode.Restart,
    )
)
val brush = Brush.horizontalGradient(
    colors = shimmerColors,
    startX = translateAnim - 300f,
    endX = translateAnim,
)
```

**Skeleton card structure** (3 cards, each matching `DiscoverProductCard` dimensions):
- Image placeholder: `Box(Modifier.fillMaxWidth().aspectRatio(16f/9f).background(brush, radius16))`
- Title placeholder: `Box(Modifier.fillMaxWidth(0.75f).height(16.dp).background(brush, radius8))`
- Description line 1: `Box(Modifier.fillMaxWidth(0.9f).height(13.dp).background(brush, radius8))`
- Description line 2: `Box(Modifier.fillMaxWidth(0.6f).height(13.dp).background(brush, radius8))`
- Price placeholder: `Box(Modifier.fillMaxWidth(0.35f).height(14.dp).background(brush, radius8))`
- Spacing between placeholder rows: `gap8` (8 dp)
- Card outer shape + padding: identical to `DiscoverProductCard`

Show 3 skeleton cards for both popular loading and web search loading states.

Source: CONTEXT.md D-38 (skeleton style), Claude's discretion on brush and animation.

### Empty States

**Community section empty** (`discover_empty_popular`):
- Full-width `Column(horizontalAlignment = CenterHorizontally, modifier = Modifier.padding(32.dp))`
- No icon (text-only per GiftMaison convention for secondary empty states)
- Single `Text` with `bodyM` style, `inkFaint` color, `textAlign = TextAlign.Center`
- Copy: "Popular items will appear here once people add gifts." (en) / "Articolele populare vor apărea aici pe măsură ce oamenii adaugă cadouri." (ro)

**Search empty** (`discover_empty_search`):
- Same layout as community empty
- Copy: "No matches found. Try a different search." (en) / "Niciun rezultat. Încearcă o altă căutare." (ro)
- Visible only when search state is `SearchState.Empty`

Source: CONTEXT.md D-41, Claude's discretion on empty state layout.

### Error States

Inline error layout (not a full-screen takeover) rendered in place of the section's content:

- `Column(horizontalAlignment = CenterHorizontally, modifier = Modifier.padding(16.dp))`
- `Text(errorMessage, style = bodyM, color = inkFaint, textAlign = TextAlign.Center)`
- Vertical gap: `gap8` (8 dp)
- `Button(onClick = onRetry, colors = ButtonDefaults.buttonColors(containerColor = accent, contentColor = accentInk), shape = pill)`
  - Label: `Text(stringResource(R.string.discover_retry), style = bodyMEmphasis)`

Error copy strings:
- Popular load error: `discover_error_load` = "Could not load. Try again." / "Nu s-a putut încărca. Încearcă din nou."
- Search error: `discover_error_search` = "Search failed. Try again." / "Căutarea a eșuat. Încearcă din nou."

Source: CONTEXT.md D-38, D-41.

### Snackbar — No Browser

- Triggered from `SnackbarHostState.showSnackbar(message)` inside `LaunchedEffect`
- Message: `R.string.discover_no_browser_toast` = "Could not open browser" / "Nu s-a putut deschide browserul"
- Duration: `SnackbarDuration.Short` (2 seconds) — Material3 default
- Position: bottom of `Scaffold`, above bottom nav bar — standard `SnackbarHost(snackbarHostState)` placement in `Scaffold(snackbarHost = …)`
- No action button on this snackbar
- Source: CONTEXT.md D-33, Claude's discretion on duration.

## Screen Layout Contract

```
Scaffold
├── topBar: none (Discover is a nav root; no back arrow; no top app bar)
├── snackbarHost: SnackbarHost(snackbarHostState)
└── content:
    ├── [gap20 top padding]
    ├── OutlinedTextField (search bar, horizontal edge 16 dp)
    ├── [gap16 spacing]
    └── LazyColumn (contentPadding = PaddingValues(horizontal = 16.dp, bottom = 24.dp))
        ├── [if searchState != Idle]
        │   ├── item: SectionHeader("FROM THE WEB")
        │   └── when searchState:
        │       Loading  → items(3) { ShimmerCard() }
        │       Loaded   → items(products) { DiscoverProductCard(it) }
        │       Empty    → item { EmptyStateText(discover_empty_search) }
        │       Error    → item { InlineErrorState(discover_error_search, retry) }
        │       Idle     → [nothing]
        │   [HorizontalDivider between sections when both visible]
        ├── item: SectionHeader("FROM THE COMMUNITY")
        └── when popularState:
            Loading  → items(3) { ShimmerCard() }
            Loaded   → items(products) { DiscoverProductCard(it) }
            Empty    → item { EmptyStateText(discover_empty_popular) }
            Error    → item { InlineErrorState(discover_error_load, retry) }
```

## Interaction States Summary

| State | Trigger | Visual |
|-------|---------|--------|
| Idle (initial) | Screen opens | Search bar empty; "FROM THE COMMUNITY" with shimmer → loaded or empty |
| Search loading | User presses Search IME action | "FROM THE WEB" section appears above community with 3 shimmer skeletons; keyboard dismissed |
| Search loaded | `discoverSearch` Callable returns | Web section shows cards; community section remains visible below |
| Search empty | Callable returns empty `products[]` | Web section shows `discover_empty_search` text |
| Search error | Callable throws / network error | Web section shows `discover_error_search` + Retry button |
| Popular loading | `init {}` fires `loadPopular()` | 3 shimmer skeletons in community section |
| Popular loaded | `discoverPopular` returns | Community section shows up to 20 cards |
| Popular empty | `popularItems` collection empty | Community section shows `discover_empty_popular` text |
| Popular error | Callable throws | Community section shows `discover_error_load` + Retry button |
| Card tap | User taps `DiscoverProductCard` | `Intent.ACTION_VIEW` launches browser; if `ActivityNotFoundException` → Snackbar |
