## Spacing Scale

Multiples of 4. Derived from handoff "Spacing / radii / shadows" + responsive table. Page padding is breakpoint-conditional.

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| 0 | 0 | `p-0` | Reset |
| 1 | 4px | `p-1` | Hairline gaps inside pills, icon offset |
| 2 | 8px | `p-2` | Pill internal padding (vertical), tight inline gaps |
| 3 | 12px | `p-3` | Gap between status row + price row inside item card body |
| 4 | 16px | `p-4` | **Mobile page padding**, item-grid gap (mobile) |
| 5 | 20px | `p-5` | Item-grid gap (≥ 1024 px), in-card body padding |
| 6 | 24px | `p-6` | Reserve detail padding, info card padding |
| 7 | 28px | `p-7` | **Tablet (640–1024 px) page padding** (handoff-mandated value, must extend Tailwind spacing scale: `'7': '28px'`) |
| 8 | 32px | `p-8` | Section padding (intra-page) |
| 9 | 36px | `p-9` | Reserve page top padding (desktop) |
| 10 | 40px | `p-10` | **Desktop (≥ 1024 px) page padding**, hero top padding (desktop) |
| 12 | 48px | `p-12` | Hero top padding desktop alternate; section breaks |

**Vertical rhythm (selected):**
- Hero block: 48 px top / 36 px bottom on desktop, 32 px top / 24 px bottom on mobile.
- Item grid section: 32 px top / 48 px bottom on desktop, 16 px / 32 px on mobile.
- Reserve sticky banner: 14 px vertical / 16 px (mobile) – 40 px (desktop) horizontal.

**Exceptions (touch / a11y minima):**
- Tap targets: ≥ 44 px on mobile, ≥ 40 px on tablet, ≥ 36 px on desktop (handoff "Responsive behaviour" + a11y).
- Sticky CTAs on mobile: 8–12 px above the safe-area inset (`env(safe-area-inset-bottom)`); banner backdrop has 1 px `gm.line` top-border.
- Convert modal as bottom sheet on mobile is **deferred to follow-up phase** (screen 04 OUT of scope per CONTEXT D-03).

**Component-internal padding exceptions (intentional, non-grid):**
- `<Btn>` internal paddings: `sm` = 7/12 px, `md` = 11/18 px, `lg` = 14/22 px (vertical / horizontal). Sourced verbatim from `design_handoff_web_giver_flow/reference/web-screens.jsx` `Btn` atom. Tuned for optical text-alignment within pill-shaped (radius 999) buttons; they are component-internal and do NOT affect page-grid alignment. The page-level spacing scale above is fully ×4-multiple.
- Sticky reserve banner vertical 14 px (rendered between handoff `ink` bg and `paper` text rows). Same rationale: optical alignment of the pulsing dot + countdown + CTA row inside a flat full-width banner; component-internal, not a grid value.

Both exceptions are explicit, traceable to the prototype contract, and bounded to component internals. They do not propagate into page-level layout, gap, or stacking values.

## Typography

Roles per handoff "Type scale" section. Two weights total: 400 + 500. Italic display serif is reserved for emphasised phrases inside headlines and the wordmark's terminal period accent — always paired with `gm.accent`. Never use italic display serif as default body or non-emphasis copy.

| Role | Font | Weight | Size desktop / mobile | Letter-spacing | Line-height |
|------|------|--------|-----------------------|----------------|-------------|
| Display XL (page hero — screen 01 headline, screen 05 headline) | Instrument Serif | 400 | 56 / 36 px | -1.4 px | 1.0 |
| Display L (section / modal — screen 02 main headline, screen 03 headline, screen 04 headline) | Instrument Serif | 400 | 44 / 28 px | -1.0 px | 1.05 |
| Display M (sub-headline / section title — "The list") | Instrument Serif | 400 | 34 / 24 px | -0.8 px | 1.05 |
| Display S (card title featured / confirm-back headline) | Instrument Serif | 400 | 22 / 20 px | -0.4 px | 1.1 |
| Body L (hero subline, primary body) | Inter | 400–500 | 16 / 15 px | -0.2 px | 1.55 |
| Body M (default body, default button label) | Inter | 400–500 | 14 / 14 px | -0.1 px | 1.5 |
| Body S (caption, info card body, hint text) | Inter | 400–500 | 13 / 12.5 px | 0 | 1.4 |
| Mono caps (labels, meta, status pill copy, "EN / RO", "© giftmaison …") | JetBrains Mono | 500 | 10–12 px (11 default; 10 micro; 12 emphasis) | 1.2–1.5 px (depending on size) | 1.3 |

**Status pill copy specifics (CONTEXT D-16):** mono-caps, 11 px small / 12 px regular, letter-spacing 0.3 px, `text-transform: uppercase`, weight 500, `white-space: nowrap`.

**Wordmark (CONTEXT D-13):** `<Wordmark />` component renders `giftmaison.` with Instrument Serif italic at 22 px (default) or 24 px (top nav), letter-spacing -0.2 px, `lineHeight: 1`, color `gm.ink`. The terminal `.` is a `<span>` with `color: gm.accent`. Optional `withTag` prop renders `gift registry` mono caps, 10 px, letter-spacing 1.5 px, `gm.inkFaint`.

**Tab CTA labels and primary buttons** use Body M weight 500 (Inter), letter-spacing -0.1 px, `lineHeight: 1` (button-tight).

**Italic display rule (re-stated for the executor):** the only places italic display serif appears in this phase are:
1. The terminal period accent in the `<Wordmark />`.
2. The emphasised phrase inside a Display XL or Display L headline (e.g. *at last* on screen 01, *Now finish the purchase* on screen 02, *Pick up* on screen 03). The italic span MUST also receive `color: gm.accent`.

3. Primary "Continue to {retailer} →" CTA on the sticky reservation banner.
4. The accent-coloured "I completed the purchase ✓" CTA on the confirm-back card (screen 02 / on-page reserve-detail section).
5. The pulsing reserved dot on the sticky banner, on Reserved item-card status pill, and on the in-card reserved banner.
6. The Reserved item-card status pill text + dot.
7. The progress bar fill on the registry hero "Progress" widget AND the time-to-purchase progress bar inside the reserve-detail card.
8. The focus-visible outline ring (2 px outline, 2 px offset).
9. The "Sign in" tab underline indicator on screen 03 (when active tab = Sign in or Create account, the active tab's 2 px bottom border is `gm.ink` — NOT accent. Accent is reserved for the per-screen italic emphasis only on this screen.)

**Destructive:** none in this phase. **Contrast guard rails (handoff a11y):**
- `gm-ink` on `gm-paper` is 13:1 (passes AAA).
- `gm-accent` on `gm-paper` is 4.6:1 (passes AA for UI / 18px+ but NOT AA for body text). **Never put body text in `gm-accent` on `gm-paper`.** Body text must be `gm-ink` or `gm-inkSoft`.
- `gm-paper` on `gm-ink` (sticky banner) is 13:1.
- The `30%-opacity paper border` on the quiet "Release reservation" button is decorative; the white-on-ink text supplies the contrast.
