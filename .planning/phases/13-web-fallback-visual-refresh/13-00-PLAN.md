```css
  --gm-second:     #4F7050;
  --gm-secondSoft: #D7E2CE;
  --gm-ok:         #4F9668;
  --gm-warn:       #D29447;

/* Phase 13 — single shared pulse keyframe (CONTEXT D-11).
   Applied to: sticky banner pulse dot (10 px), Reserved item-card pill leading
   dot (8 px), in-card reserved banner leading dot (8 px). Cadence 1.4 s alternate
   matches Android Phase 9 PulsingDot constants — cross-app consistency. */
@keyframes gm-pulse {
  0%, 100% { opacity: 1; transform: scale(1); }
  50%      { opacity: 0.5; transform: scale(0.85); }
}

@media (prefers-reduced-motion: reduce) {
  /* Reduced-motion fallback — fade only, no scale. */
  @keyframes gm-pulse {
    0%, 100% { opacity: 1; transform: scale(1); }
    50%      { opacity: 0.5; transform: scale(1); }
  }
}
```

Notes:
- The reduced-motion `@keyframes gm-pulse` re-declaration inside the `@media` block re-defines the named animation at runtime when the user opts out of motion — Tailwind's `animate-gm-pulse` utility (defined in Plan 00 Task 1) resolves to this keyframe by name, so no extra class is required at the consumer site (Plan 01's `<PulseDot />`). UI-SPEC also lists a `gm-pulse-fade` keyframe variant — this implementation collapses both into one named animation, simpler and equivalent.
- The original `font-family: 'Inter'` declaration on `:root` stays for now; the body's `font-body` Tailwind class will take precedence on every component once Plan 02 + Plan 04+ rewire pages.
