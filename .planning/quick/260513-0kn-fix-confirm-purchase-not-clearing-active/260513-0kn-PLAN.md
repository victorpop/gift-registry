<objective>
Fix the bug where clicking "I completed the purchase" flips the item to PURCHASED server-side but the StickyReserveBanner and ReserveDetailSection remain visible because `useActiveReservation.active` is never cleared on the client. The confirmPurchase callable already atomically sets `reservation.status = 'purchased'` and `item.status = 'purchased'`; the item card flips via Firestore snapshot; the only missing piece is clearing the local React context that gates both the sticky banner and the in-page detail section.

Purpose: Restore the contract that successful purchase confirmation tears down the in-flight reservation UI in the same tab — no refresh, no leftover "I completed the purchase" CTA on an already-purchased item.

Output: One-line addition inside the existing success `useEffect` in `ConfirmPurchaseBanner.tsx` (calls `clear()` from `useActiveReservation`), plus one regression test asserting that contract.
</objective>
