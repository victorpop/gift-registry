Today, finding a product in Discover only opens the retailer page in a browser — there is no path to capture the product into a registry without manually copy-pasting the URL into Add Item. This single tap collapses that flow.

Output: Two code paths — (1) a new optional prefill block on AddItemKey + AddItemViewModel that hydrates form state without triggering the OG-fetch Cloud Function, and (2) a new small button overlay on DiscoverProductCard with the wiring to navigate into that prefill path. Plus localized strings (en+ro) and a unit test pinning the no-OG-fetch contract.
